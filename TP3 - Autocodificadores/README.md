# TP3 - Autocodificadores

## Descripción

Trabajo práctico desarrollado para la materia **Fundamentos de Redes Neuronales**, enfocado en el diseño, entrenamiento y análisis de **autocodificadores (Autoencoders)** utilizando Python.

## Objetivos

* Implementar un autoencoder para representar imágenes binarias de caracteres.
* Analizar distintas arquitecturas y parámetros de entrenamiento.
* Visualizar el espacio latente en dos dimensiones.
* Generar nuevos caracteres a partir del espacio latente.
* Implementar un autoencoder eliminador de ruido (Denoising Autoencoder).
* Evaluar el desempeño del modelo con distintos niveles de ruido.
* Generar nuevas muestras mediante autoencodificadores.

## Contenido

* Diseño de la arquitectura del codificador y decodificador.
* Entrenamiento del modelo.
* Representación del espacio latente.
* Generación de nuevos caracteres.
* Eliminación de ruido en imágenes.
* Análisis de resultados y conclusiones.

## Tecnologías utilizadas

* Python
* Google Colab
* TensorFlow
* Keras
* NumPy
* Matplotlib

## Resultados

Se evaluó el comportamiento de diferentes arquitecturas de autoencodificadores, analizando su capacidad para comprimir información, reconstruir imágenes, eliminar ruido y generar nuevas muestras a partir del espacio latente.
