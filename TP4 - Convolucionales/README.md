# Clasificación de Imágenes con Redes Neuronales Convolucionales

Proyecto de Deep Learning enfocado en la clasificación de imágenes utilizando Redes Neuronales Convolucionales (CNN) y Transfer Learning.

El objetivo fue desarrollar y comparar dos modelos capaces de clasificar imágenes en 8 categorías de animales.

## Descripción

Se implementó una CNN personalizada diseñada desde cero, evaluando diferentes arquitecturas e hiperparámetros como cantidad de capas, filtros, funciones de activación, optimizador y tasa de aprendizaje.

Además, se desarrolló una solución basada en Transfer Learning utilizando un modelo preentrenado, adaptando su arquitectura mediante una nueva capa de clasificación y aplicando técnicas de Fine-Tuning para mejorar los resultados.

## Tecnologías utilizadas

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib
- Scikit-learn
- OpenCV

## Funcionalidades

- Preprocesamiento y normalización de imágenes.
- División de datos en entrenamiento y prueba.
- Clasificación multiclase mediante salida Softmax de 8 neuronas.
- Entrenamiento de una CNN propia.
- Implementación de Transfer Learning.
- Evaluación y comparación de modelos.
- Inferencia sobre nuevas imágenes.

## Evaluación

Los modelos fueron evaluados utilizando métricas como Accuracy, Loss, Validation Accuracy y Validation Loss.

Se analizaron los resultados obtenidos para comparar el rendimiento entre la arquitectura creada desde cero y el modelo preentrenado.

## Aprendizajes

Durante el desarrollo se aplicaron conceptos de:

- Redes Neuronales Convolucionales.
- Procesamiento de imágenes.
- Transfer Learning.
- Fine-Tuning.
- Ajuste de hiperparámetros.
- Entrenamiento y evaluación de modelos de Deep Learning.
